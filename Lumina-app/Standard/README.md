# Lumina Standard v1.5

Versão padrão do Lumina Dashboard com funcionalidades essenciais.

## ✨ Funcionalidades Incluídas

- ✅ Dashboard responsivo
- ✅ Controle de dispositivos Hubitat
- ✅ Tema Highline (principal)
- ✅ Organização por salas
- ✅ EventStream (atualizações em tempo real)
- ✅ Modo escuro/claro
- ✅ Layout drag & drop

## 🚫 Funcionalidades PRO (não incluídas)

- ❌ Sistema de temas avançado
- ❌ Câmeras IP
- ❌ Sistema de favoritos  
- ❌ Layout sidebar (SmartHome Pro)
- ❌ IA Chat integrado

## 📊 Especificações

- **Arquivo:** `Lumina_Standard.html`
- **Tamanho:** ~664KB
- **Tecnologia:** React + TailwindCSS + Vite (single-file)
- **Compatibilidade:** Hubitat Elevation (qualquer versão)
